# Unterrichtsplanung – jetzt auch ohne Papierstapel

Diese Datei macht aus der Unterrichtsplanung ein lokal laufendes, editierbares Formular. Keine Anmeldung, kein WLAN, keine pädagogisch wertvollen Ladebalken.

## Start

`unterrichtsplanung.html` doppelklicken und im Browser öffnen. Fertig. Wirklich.

## Was kann das Ding?

- Stundenplanung und Lernziele frei eintragen
- Unterrichtsphasen ergänzen, kopieren, löschen und verschieben
- Vorschläge aus Kombinationsfeldern wählen oder einfach selbst etwas Besseres hineinschreiben
- Lange Texte in den großen Textfeldern erfassen – sie wachsen mit
- Eingaben automatisch im Browser speichern
- Daten als JSON sichern oder wieder einlesen
- Als A4-PDF drucken

## Die kleinen Pfeile in den Feldern

Ein Klick auf den Pfeil zeigt immer alle passenden Vorschläge. Tippen im Feld grenzt die Liste ein. Freitext bleibt erlaubt, denn Unterricht läuft bekanntlich selten exakt nach Auswahlliste.

## PDF-Export

1. Oben auf **„Drucken / als PDF speichern“** klicken.
2. Im Browser **„Als PDF speichern“** auswählen.
3. Wenn die Browser-Adresse nicht als Fußzeile mit aufs Zeugnis möchte: **„Kopf- und Fußzeilen“** deaktivieren.
4. Speichern, bewundern, unterrichten.

## Hinweis zum Speichern

Die automatische Speicherung nutzt den lokalen Speicher des Browsers. Wer den Browser-Speicher löscht, löscht damit leider auch die Planung. Für besonders kostbare Unterrichtsmeisterwerke daher gelegentlich **„JSON exportieren“** benutzen.
